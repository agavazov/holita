# Supplied Simple eData FMS Monitor binaries

This directory retains user-supplied vendor source files for repeatable offline analysis.
`Simple eData FMS Monitor v9.56.exe` is the sole required catalog input. Its SHA-256 is
`01dd13e50c55fdf84078ce298bde72320d55bee458baa4c0d2a06fca7c0ca1a0`.
The filename supplies the package label; Windows file/product version fields are absent.

`Simple eData FMS Firmware v9.56.ini` is an accompanying firmware image, not a user
configuration export or catalog input. The extractor does not execute or flash either
file. Retain new Monitor versions alongside these original binaries.

See the [catalog and direct-command procedure](../../../docs/discocan/erm-resources/simple-edata-catalog/README.md)
and [v9.56 extraction](../../../docs/discocan/erm-resources/simple-edata-catalog/v9.56/README.md).
