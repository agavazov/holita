# Foundation requirements

These criteria describe the current workspace and local application foundation.
The contract includes persistence, schema-first Stores/Products/Reference APIs and the Angular
admin in Real and Prototype. Sakai is its theme and visual reference; the
[pinned source](../development.md#sakai-source-reference) defines shell and feature composition.
Angular implements
Stores, Products and Reference Venues/Speakers/Tags/Events/Sessions/Gallery/History, plus a local
Prototype UI catalog. Both Angular modes use the same business components and generated contracts.
