# Project backlog

Pending work and planned tasks, separate from implemented product documentation.

- [ERM roadmap](erm-roadmap.md): fleet routing, safety/test levels, device control, recovery,
  questions for ERM, owner decisions and production deployment.
- [Admin presentation and release](admin-design-system.md): remaining product/release decisions.
- [Admin backend follow-ups](admin-design-system-backend.md): unresolved provider integrations.
- [Instant tasks](_instant-tsks.md): short one-line tasks.

Karma is deprecated, view-only. Former Karma backlogs and interface/API research are in the
[reference archive](../archive/karma/README.md), not active delivery plans. Open ERM questions
have moved to the roadmap.

Use an existing component backlog before adding another description. Larger plans use descriptive
Markdown files here. Write in English, distinguish proposals from implemented behavior and remove
completed/cancelled tasks. Keep product documentation in
[Discocan](../discocan/README.md), [Ecommerce](../ecommerce/README.md) or the
[shared workspace](../README.md). Do not keep verification journals or handoffs here.
When no short tasks remain, retain the instant file with `No open instant tasks.`

Report checks in the task response, following the [contributor rules](../../AGENTS.md).
