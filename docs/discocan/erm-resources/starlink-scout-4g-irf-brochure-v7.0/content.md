### StarLINK Scout - Compact Telematics Solution

StarLink Scout is described as a compact telematics solution for fleet management, with ERM safety functionality for driver behavior analysis, advanced power management and optional additional features.

### Features

1. Miniature size.
2. Embedded cellular and GPS antennas.
3. Internal backup battery.
4. Support for up to 50 GeoZones (optional).
5. Immobilization and Driver ID support (optional).
6. Extensive safety features for driver scoring (optional).
7. Temperature sensor support (optional).

### Available variants

The badge strip displays **4G, SF, DS, GO, iRF**.

| Badge | Visible description                                                                                                                                                      |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| iRF   | Bluetooth Low Energy module for communication with a mobile phone/tablet and for reading external sensors and tags.                                                      |
| GO    | Extended geofencing with up to 50 geofences.                                                                                                                             |
| DS    | Temperature sensor support.                                                                                                                                              |
| 4G    | 4G LTE CAT1/4 cellular module supporting global standard band frequencies and 2G fallback.                                                                               |
| SF    | 3D high-sensitivity accelerometer and gyro with ERM Safety technology; detection of 20 maneuver types at three intensity levels and event-based driving-behavior alerts. |

### Technical specifications

| Item                            | Visible specification                                                                                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cellular                        | LTE Bands CAT-1; 2G/GPRS backward compatibility; optimized embedded antenna.                                                                                              |
| Location                        | GPS/GLONASS/GALILEO; active antenna; sensitivity -165 dB; NMEA0193; normal acquisition: cold <34 s, warm <34 s, hot <1 s; accuracy 2.5 m CEP; embedded optimized antenna. |
| Communication                   | Text messages; TCP/IP over GPRS/LTE; Bluetooth 2.4 GHz v5.3.                                                                                                              |
| Connectors                      | 8-pin Molex connector.                                                                                                                                                    |
| I/O ports                       | 2 inputs, 2 outputs and one eNet/Dallas/input line; Dallas Driver ID and Dallas temperature sensor support.                                                               |

| Power supply                    | 9-32 VDC; 20-30 mA average; low-power mode with GPS off <10 mA; power-save standby <3.0 mA average.                                                                       |

| Configuration / firmware update | OTA or standard PC USB port; parameter setup and software programming.                                                                                                    |
