## Analysis

The visible brochure presents a compact unit with embedded cellular/GPS antennas and a backup battery. Optional features include geozones, immobilization/driver identification, safety analysis and temperature sensing (page 1).

The visible variant badges are 4G, SF, DS, GO and iRF. The table lists an 8-pin Molex connector, two inputs, two outputs, an eNet/Dallas/input line, an ignition port, 9-32 VDC supply, a 3.7 V / 350 mAh battery and a 5,000-message logger (page 2). The environment table gives 8.2 x 4.5 x 2 cm and 38 g (page 3).

This is a marketing/specification reference with a version inconsistency. It does not provide a wire protocol, parameter dictionary or proof of a particular installed device configuration.
