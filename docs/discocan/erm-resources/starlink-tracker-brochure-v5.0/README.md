## Analysis

The brochure presents a configurable telematics device with embedded and external add-on variants for fleet management, vehicle diagnostics and driver/passenger safety. Its visible feature list includes 4G with 2G fallback, immobilization, geozones, FOTA, embedded antennas, battery diagnostics, a single-wire accessory port, output logic programming, OTA configuration and optional Wiliot gateway support (pages 1-2).

The variant section distinguishes cellular, Wi-Fi, Bluetooth, safety/BlackBox, CAN Engine, RS232, external antennas, eConnect, voice, driver ID and Wiliot functions. The CAN variant text states support for up to twelve parameters including the odometer; it is not the same limit as the separate Simple eData Monitor guide (page 2).

The specification table lists a 10-pin Molex connector, up to four inputs and four outputs, optional analog inputs, eNet accessory wiring, 9-80 VDC supply, a 3.6 V / 750 mAh battery and 5,000-60,000 logged messages depending on variant. IP65 is conditional on the optional rubber cover (page 3).
