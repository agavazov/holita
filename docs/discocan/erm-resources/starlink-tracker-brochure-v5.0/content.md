### StarLink Tracker - Ultimate, Function Rich Telematics Solution

The brochure describes StarLink Tracker as a configurable telematics device with variants for fleet management, vehicle diagnostics, driver/passenger safety and connected-car applications. Additional capabilities may be embedded or supplied through external add-ons and accessories during or after installation.

The publisher claims compatibility with most vehicle types and worldwide automotive, radio and safety standards; the page does not identify the individual standards or certificates. These remain brochure claims.

### Features

1. 4G cellular module with fallback to 2G.
2. Immobilization system.
3. Geo-zone protection.
4. FOTA.
5. Embedded antennas.
6. Vehicle battery diagnostics: charge, voltage and battery life (SoH).
7. Dedicated single-wire communication port for add-ons and accessories.
8. Output Logic Programming (OLP) for complex output signal generation.
9. Full OTA support for firmware, configuration, I/O setup, alert rules, geofencing and more.
10. Optional gateway support for Wiliot Pixel technology (WG variant).

### Available variants

The badge strip displays **4G, SF, iRF, CAN, ID, EC, 22, EA, VO, WF, WG**.

| Badge | Visible description                                                                                                                                                        |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4G    | 4G LTE CAT1/4 cellular module for global standard band frequencies, with 2G fallback.                                                                                      |
| WF    | Wi-Fi hotspot supporting up to eight simultaneous connections, or Wi-Fi client connection to a third-party hotspot.                                                        |
| iRF   | Bluetooth Low Energy module for mobile phone/tablet communication and reading external sensors/tags.                                                                       |
| SF    | 3D high-sensitivity accelerometer and gyro, ERM Safety technology and BlackBox functionality; 20 maneuver types at three intensity levels with event-based driving alerts. |
| CAN   | ERM CAN Engine interface for CANBUS, OBD2 and FMS J1939; up to 12 parameters including the odometer.                                                                       |
| 22    | Serial RS232 port for supported external serial devices.                                                                                                                   |
| EA    | External GPS and cellular antenna ports to improve communication where internal antennas have limited performance, such as armored vehicles.                               |
| EC    | ERM eConnect RF technology for alternative communication between vehicles when cellular/GPS signals are jammed; 433 MHz or 915 MHz, depending on the request.              |
| VO    | Voice communication with an external speaker and dedicated microphone; optional ERM keypad or push button for quick dialing and manual answering/disconnection.            |
| ID    | Driver identification with black/white lists, two proximity remote controls (eCom Tags) and support for additional identification methods/tags.                            |
| WG    | Wiliot Pixel support using iRF 2.4 GHz Bluetooth Low Energy for two-way communication; gateway transmission of Pixel data to the cloud.                                    |
