# Ecommerce: online shops

Ecommerce is the online-shop domain, distinct from Discocan fleet telemetry.
The current foundation is Core Tenant/Branch discovery and lookup. Storefront, catalog,
cart, checkout and orders are not implemented.

- [Contributor instructions](instructions.md).
- [Branches foundation](branches.md): current ownership, contracts, source references and checks.
- [Shared workspace documentation](../README.md): architecture, development and validation.

Branch is the shared organizational scope. In Ecommerce, a Branch represents an online
shop; in [Discocan](../discocan/README.md#terminology), it represents a vehicle fleet.
Both domains use the same Core-owned Branch model and tenant-scoped discovery contract.
The current telemetry admin and Fleet modules belong to Discocan documentation.
