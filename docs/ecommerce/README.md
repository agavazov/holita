# Ecommerce: online stores

Ecommerce is the online-store domain, distinct from Discocan fleet telemetry.
The current foundation is Core Tenant/Store discovery and lookup. Storefront, catalog,
cart, checkout and orders are not implemented.

- [Contributor instructions](instructions.md).
- [Stores foundation](stores.md): current ownership, contracts, source references and checks.
- [Shared workspace documentation](../README.md): architecture, development and validation.

Stores remains the term for online shops. Discocan currently reuses the same Core foundation
for organizational scope, but its Stores will later become [Branches](../discocan/README.md#terminology).
The current telemetry admin and Fleet modules belong to Discocan documentation.
