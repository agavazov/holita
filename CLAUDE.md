The delivery policy in `AGENTS.md` comes first. Choose Discocan or Ecommerce using the domain
routing in `AGENTS.md`, apply its contributor instructions, and read only the documentation the
task needs, starting from [docs/README.md](docs/README.md). The shared guide above applies when
developing this repository with Claude Code. The optional, Git-ignored `AGENTS.local.md` adds
this checkout's local instructions; a missing file is skipped.

Keep this entry point short. Maintain shared rules in `AGENTS.md` and product documentation
in `docs/`, so Codex and Claude use the same source of truth.
